## 📌 Overview

**SkillSync AI** is a smart, gamified platform built for students and early-career developers who want to grow faster and smarter.

Instead of guessing what to learn next, SkillSync AI analyzes your current skills, compares them against real job requirements, and gives you a **week-by-week personalized roadmap** — complete with resources, projects, and progress tracking.

Think of it as your personal AI mentor that never sleeps. 🤖

---

## ❗ Problem Statement

Students today face a very real and frustrating challenge:

- 📚 They study a lot — but still feel **unprepared for jobs**
- 🔍 They don't know **which skills** actually matter for their target role
- 🗺️ There's no clear **roadmap** from where they are to where they want to be
- 📉 Self-learning without structure leads to **wasted time** and **loss of motivation**
- 🏆 No way to **measure progress** or compare with peers

> Most existing platforms give you courses. Nobody gives you a **plan**.

---

## ✅ Solution

SkillSync AI bridges the gap between **where you are** and **where you want to be**.

It connects your GitHub profile, analyses your current skill set, and uses AI to:

1. **Identify** what skills you already have
2. **Detect** gaps compared to your target role
3. **Generate** a personalized, week-by-week learning roadmap
4. **Track** your daily progress with XP, streaks, and leaderboard rankings
5. **Motivate** you with badges, gamification, and an AI mentor chatbot

## ⚙️ How It Works

```
  USER SIGNS UP
       │
       ▼
  Enters Target Role + Skills
  (or connects GitHub profile)
       │
       ▼
  AI Analyses Skill Gap
  (compares with job market data)
       │
       ▼
  Personalized Roadmap Generated
  (week-by-week plan with resources)
       │
       ▼
  User Completes Daily Tasks
  (earns XP, maintains streak)
       │
       ▼
  Progress Tracked on Dashboard
  (leaderboard, badges, level-up)
       │
       ▼
  AI Mentor Available 24/7
  (answers questions, adjusts plan)
```

**Step-by-step breakdown:**

**Step 1 — Sign Up & Setup**
Create your account, enter your name, target role (e.g., Backend Developer), and connect your GitHub profile.

**Step 2 — Skill Detection**
The AI scans your GitHub repositories, project descriptions, and declared skills to understand your current level.

**Step 3 — Gap Analysis**
SkillSync AI compares your skills against curated job profiles and identifies exactly what's missing.

**Step 4 — Roadmap Generation**
A 6-month, week-by-week roadmap is generated with topics, resources, and mini-projects tailored just for you.

**Step 5 — Daily Learning & Tracking**
You complete tasks, earn XP, maintain your streak, and watch your progress bars grow in real-time.

**Step 6 — Level Up & Compete**
Climb the global leaderboard, unlock badges, level up, and stay ahead of your peers.

## 🚀 Installation

Follow these steps to run SkillSync AI locally on your machine.

### Prerequisites

Make sure you have the following installed:
- Python 3.10+
- pip
- Git

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/skillsync-ai.git
cd skillsync-ai
```

### 2️⃣ Create a Virtual Environment

```bash
# Create virtual environment
python -m venv venv

# Activate it
# On Windows:
venv\Scripts\activate

# On Mac/Linux:
source venv/bin/activate
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```env
SECRET_KEY=your_django_secret_key_here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

# AI Integration
OPENAI_API_KEY=your_openai_api_key_here

# GitHub API
GITHUB_API_TOKEN=your_github_token_here

# Database (optional — defaults to SQLite)
DATABASE_URL=your_database_url_here
```

### 5️⃣ Run Database Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6️⃣ Create a Superuser (Admin)

```bash
python manage.py createsuperuser
```

### 7️⃣ Start the Development Server

```bash
python manage.py runserver
```

### ✅ Open in Browser

```
http://127.0.0.1:8000/
```

> 🎉 That's it! SkillSync AI should now be running locally.
